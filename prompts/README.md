# Prompts

| File | Use |
|---|---|
| `full-tags-prompt.md` | Default system prompt for `scripts/s4-agent/verifier/*` (acoustic QC + transcript tags). |
| `full-tags-prompt-detached-consonants.md` | Variant with Vietnamese-style vowel spelling and a closed table of detached consonants in ViePhoneme. Pass with `-pf`. |
| `archive/` | Earlier prompts, kept for reference. No command uses them by default. |

Experiments must name the prompt file they used in `WORKLOG.md`.
